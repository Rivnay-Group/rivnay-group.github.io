# Rivnay Group website — design spec

Date: 2026-09-06. Replaces the Squarespace site at rivnay.northwestern.edu.

## Goals

- Clean, left-aligned, fast static site that a lab member can edit by changing a YAML file or adding a markdown post.
- Carry over every person, bio, headshot, publication, and news post (61) from the current site, with typos fixed.
- Publications stay current via a script instead of hand-typing.
- Visual identity belongs to the Rivnay Group (organic mixed conductors, biohybrid "cell factories", electrochemical aptamer sensors, regenerative scaffolds), not borrowed from the Asilomar site.

## Non-goals

- No CMS, no JavaScript framework, no search, no comments, no analytics.
- No per-person pages. No tag or category filtering on News.
- DNS cutover to rivnay.northwestern.edu is documented, not performed.

## Stack

- Jekyll (GitHub Pages default build, Jekyll 3.10 compatible: no plugins beyond `jekyll-seo-tag`, plain CSS, no Sass features that differ between 3 and 4).
- Repo `jtwillia01/rivnay-lab`, Pages served from `main` root. `baseurl: /rivnay-lab` until the custom domain is set; every link uses `relative_url`.
- Local preview: Homebrew Ruby 4 + Jekyll 4.4 already installed at `/opt/homebrew/opt/ruby/bin`. `.claude/launch.json` runs `jekyll serve`.

## Data schemas

`_data/people.yml` (order within a group is the order on the page):

```yaml
- name: Abhijith Surendran
  role: Research Assistant Professor
  group: faculty        # pi | faculty | staff | postdoc | phd | masters | undergrad
  email: ...            # optional
  photo: abhijith-surendran.jpg   # assets/img/people/, 600x600
  website: https://...  # optional
  bio: >
    Paragraphs separated by blank lines.
```

Group labels and order: pi → "Principal Investigator", faculty → "Research Faculty", staff → "Research Staff", postdoc → "Postdoctoral Researchers", phd → "PhD Students", masters → "Master's Students", undergrad → "Undergraduate Students".

`_data/alumni.yml`:

```yaml
- name: Dilara Meli
  group: phd            # postdoc | phd | masters | undergrad | visiting
  year: 2025
  now: National Institute of Standards and Technology   # optional
```

`_data/publications.json` (generated by `scripts/publications.py`, do not edit; JSON so the script needs only the standard library, and Jekyll reads JSON data files natively):

```json
{"year": 2024, "authors": "Z. Laswick, X. Wu, A. Surendran, J. Rivnay", "title": "Tunable anti-ambipolar vertical bilayer organic electrochemical transistor enable neuromorphic retinal pathway", "journal": "Nature Communications", "volume": "15", "issue": "1", "pages": "6309", "doi": "10.1038/s41467-024-50496-6", "openalex": "W4400927226", "pre_northwestern": false}
```

`_data/publications_manual.json`: `{"exclude": [dois or OpenAlex IDs], "add": [entries in the same shape]}`. `add` holds the pre-2017 list and anything OpenAlex lacks. `pre_northwestern: true` on an entry puts it under the collapsed heading.

`_data/support.yml`: `funders:` and `facilities:` lists of `{name, logo, url}`.

Post front matter (`_posts/2024-08-19-bridging-length-scales.md`):

```yaml
---
title: Bridging length scales in organic mixed ionic–electronic conductors
date: 2024-08-19
kind: paper           # paper | award | people | group
image: /assets/img/news/2024-08-19-bridging-length-scales.jpg   # optional
link: https://doi.org/10.1038/s41563-024-01813-3                 # optional external link
---
Body in markdown. One-line posts are fine.
```

## Publication pipeline rules

- Source: OpenAlex author `A5066036682` (ORCID 0000-0002-0602-6485), all works, paginated by cursor.
- Keep types `article`, `book-chapter`, `review`. Drop `preprint`, `dataset`, `erratum`, `peer-review`, `conference-abstract`, `conference-paper`, `editorial`, `other`. Drop any work whose primary source type is `repository`. Drop `is_retracted`.
- Dedupe by normalized title; keep the entry with a journal source.
- Authors formatted as initials + surname (`J. Rivnay`), all authors listed. The page bolds `J. Rivnay` in CSS-free Liquid `replace`.
- Sort by year desc, then publication date desc. Entries with `pre_northwestern: true` (year < 2017 or flagged) render under a `<details>` labelled "Pre-Northwestern publications".
- The script prints a diff report against `scripts/old-site-publications.txt` (the 69 old entries plus the pre-2017 list) so nothing is silently lost; unmatched old entries go into `publications_manual.json` `add`.
- Re-run: `python3 scripts/publications.py` (stdlib only, no pip installs).

## Visual identity

- Type: headings **Source Serif 4** (weight 600), body **IBM Plex Sans** (400/500/600), small labels and DOIs **IBM Plex Mono**. Google Fonts with system fallbacks.
- Color tokens: `--purple #4E2A84` (Northwestern), `--purple-dark #3B1F63`, `--purple-tint #EFEAF5`, `--gold #B8933F` (electrode gold, used only for eyebrow rules and active nav underline), `--ink #1C1826`, `--muted #625C70`, `--ground #F7F6F3`, `--paper #FFFFFF`, `--line #E3DFEA`.
- Layout: everything left-aligned. `.wrap` max 1120px for grids, `.prose` max 720px for text. Sections separated by 4rem, eyebrow label (mono, uppercase, letter-spaced, short gold rule) above each h2.
- Header: wordmark "Rivnay Group" in serif, nav links in sans, active link underlined in gold, CSS-only hamburger under 900px, sticky with blur.
- Home hero: two columns, headline + subtitle + two buttons left, hero photo right in a 12px-radius frame. Stacks on mobile.
- People: circular 600px headshots (several existing files are pre-cut circles), name in serif, role and email in sans, bio in a native `<details>` labelled "Bio".
- Publications: year as a sticky-feeling left label on wide screens, entries as a list with title in semibold, journal in italics, DOI as a mono link.
- Footer: `--purple-dark` background, cream text.
- Dark mode: not built. Print: default.

## Copy policy

- Migrate text verbatim, then fix spelling, doubled words, casing in headings, and obvious grammar (for example "news ways" → "new ways", "enquire" → "inquire", "Rivany" → "Rivnay", "Stravrinidou" → "Stavrinidou", "Ammer" → "Ameer"). Do not rewrite meaning. Heading case: sentence case for every on-page heading (h1 included: "Our research", "The group", "Lab news", "Join the lab"); the browser <title> keeps the short nav label. The built pages are the source of truth; `docs/copy/*.md` are the intermediate verbatim-plus-typo-fix transcripts, and light grammatical smoothing in the pages (for example "sensing and stimulation" for "sensing/stimulation", removing em dashes, consistent list punctuation) is intentional and need not be logged.
- People bios: keep first-person-third style as written. Names in title case (the old site had "anna baur", "QUINN BEATo").

## Deployment

4. Custom domain later: add `CNAME` file containing `rivnay.northwestern.edu`, set `baseurl: ""`, and ask Northwestern IT for a CNAME record `rivnay.northwestern.edu → jtwillia01.github.io`. Documented in README.
